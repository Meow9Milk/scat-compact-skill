# SCAT Compact

SCAT分析表を、ストーリーラインに沿う簡潔なExcelに再構成するCodex向けスキルです。

## 配置

`scat-compact/SKILL.md` をスキルフォルダーごとCodexのスキル保存先へ配置します。通常の保存先は `~/.codex/skills/` です。GitHubで公開しただけでは自動的にはインストールされません。

## 使用例

「$scat-compact このSCAT分析を、ストーリーラインに沿って重複をまとめ、短いExcelにしてください。元の発言番号と発話者の見解の違いは残してください。」

分析表と原発言の資料を渡して使います。Excelの生成には、実行環境に表計算ファイルを作成する手段が必要です。

## 公開する内容

このパッケージには手順のみを含めています。実際のインタビュー、研究用Excel、他者の論文やWord資料は含めていません。

出力は分析者が原資料と照合して検討するための整理案です。
